I recently developed a containerized Weather API using Python and Flask, focusing on clean development practices and Docker optimization.

Tech Stack & Tools Used:

Python (Flask)

Multi-Stage Dockerfile

Docker & Docker Compose

requirements.txt for dependency management

Git for version control

GitHub for repository management

Visual Studio Code for development

- Implemented clean API architecture
- Optimized Docker image using multi-stage builds
- Managed dependencies via requirements.txt
- Version control workflows using Git
- Publishing and maintaining code repositories on GitHub
- Ensured lightweight and production-ready container

This project enhanced my understanding of Docker optimization, API development, and DevOps fundamentals.
